# Beginning C# 7 — Study Code

Code examples and exercises for learning C# 7, .NET Framework 4.7, and Visual Studio 2017-era application development.

> **Learning repository**  
> This repository contains study material associated with *Beginning C# 7 Programming with Visual Studio 2017*. It is preserved as a learning reference and should not be interpreted as a current .NET production template.

## Topics covered

The examples progress from language fundamentals into application development, including:

- Variables, expressions, flow control, and functions.
- Debugging and error handling.
- Object-oriented programming, classes, and class members.
- Collections, conversions, generics, and additional C# techniques.
- Desktop and cloud application concepts.
- .NET Standard and .NET Core concepts.
- ASP.NET / ASP.NET Core.
- Files, XML, JSON, LINQ, databases, WCF, and Universal Apps.

## Development environment

The material was created for:

- **C# 7**
- **.NET Framework 4.7**
- **Visual Studio Community 2017**
- SQL Server Express for database examples

Modern .NET development has moved significantly beyond this stack, so newer projects should use current .NET tooling unless reproducing the course environment is the objective.

## Repository structure

Examples are organised by book chapter. Start with the earlier chapters if you are learning the language, or jump directly to a topic when using the repository as a reference.
